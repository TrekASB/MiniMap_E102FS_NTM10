# MiniMap – E102FS (NTM10)

Trimble Connect MiniMap for E102FS, adapted from [MiniMap_E836Stokkv-gen_NTM13](https://github.com/TrekASB/MiniMap_E836Stokkv-gen_NTM13).

- Project CRS: EUREF89 / NTM zone 10, EPSG:5110 (model X=easting, Y=northing).
- Projection: Transverse Mercator, central meridian 10.5°, latitude of origin 58°, false easting 100000 m, false northing 1000000 m.
- Vertical reference indicated in the UI: NN2000 (no vertical transformations performed).
- All map layers, Trimble viewer integration and toolbar features retained.
- Logo and extension icon use absolute URLs pointing to the original source repository; those resources must remain available.
